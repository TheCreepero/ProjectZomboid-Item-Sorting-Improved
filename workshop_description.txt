[h1]Item Sorting Improved (Project Zomboid Build 42)[/h1]

[b]Item Sorting Improved[/b] is a lightweight, zero-maintenance sorting and categorization engine designed specifically for [b]Project Zomboid Build 42[/b].

It eliminates cluttered inventory panes and arbitrary vanilla categorization by dynamically classifying every item (vanilla, modded, and newly introduced) into a clean, intuitive, and alphabetically prefix-aligned taxonomy upon game boot.

[hr][/hr]

[h1]Key Features[/h1]

[list]
[*] [b]Zero-Maintenance Mod Compatibility[/b]: No hardcoded item lists to update. The classification engine evaluates item properties, tags, components, and attributes dynamically at runtime. Any weapon, tool, clothing item, food, or material added by any mod is automatically recognized and sorted.
[*] [b]Alphabetical Prefix-Aligned Taxonomy[/b]: Category names use consistent prefix groupings (e.g. Cloth*, Food*, Lit*, Sur*, Wep*), keeping related goods grouped together naturally when sorting inventory or containers by category.
[*] [b]Build 42 Fluid System Integration[/b]: Dynamically reacts to Build 42's liquid system. As you fill, drink, siphon, or empty fluid containers (canteens, buckets, gas cans, bottles), their category updates in real time (e.g., Water and Soda -> Food - Beverage, Gasoline -> Fuel, Bleach -> Cleaning, Empty -> Container - Liquid).
[*] [b]Dedicated Server and Loot Table Safe[/b]: Preserves internal vanilla loot table flags (such as Medical, MechanicsItem, SurvivalGear, FARMING_LOOT, and IS_MEMENTO) before modifying display parameters. Dedicated servers safely bypass client UI categorization modifications, ensuring zero interference with ItemPickerJava.
[*] [b]Safe for Existing Saves[/b]: 100% safe to add or remove at any point during an ongoing single-player or multiplayer playthrough.
[*] [b]Cosmetic and Wound Layer Filtering[/b]: Automatically filters internal damage layers, cosmetic wounds, and hidden items (ZedDmg, Wound) into Misc to prevent inventory clutter.
[*] [b]Modder and Player Override Hook[/b]: Includes a clean, decoupled override table allowing mod authors or players to define custom category assignments for specific item IDs with single-line declarations.
[*] [b]Comprehensive Localization[/b]: Full translation mapping with clean UI naming (IGUI_ItemCat_*) ready for localization into other languages.
[/list]

[h1]Custom Overrides for Modders and Players[/h1]

If you want to assign a custom category to any item without modifying the engine:

[code]
ItemSortingImproved = ItemSortingImproved or {}
ItemSortingImproved.Overrides = ItemSortingImproved.Overrides or {}

-- Format: ItemSortingImproved.Overrides["Module.ItemType"] = "CategoryKey"
ItemSortingImproved.Overrides["MyMod.PlasmaRifle"] = "WepFire"
ItemSortingImproved.Overrides["MyMod.TacticalBandage"] = "Med"
[/code]
